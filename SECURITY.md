# Security Policy

## Supported Versions

Security fixes are applied to the latest version on the default branch. Older
commits, forks, and independently deployed copies are not maintained by this
project.

## Reporting a Vulnerability

Please do not disclose suspected vulnerabilities in a public issue or pull
request.

Use GitHub's private vulnerability reporting flow:

https://github.com/iot-bin/random-redirect-link/security/advisories/new

Include the affected component, reproduction steps, expected impact, and any
suggested mitigation. Remove passwords, tokens, customer data, and other
secrets from screenshots and logs.

If private vulnerability reporting is unavailable, open a public issue asking
the maintainers for a private contact channel, but do not include vulnerability
details in that issue.

Please allow the maintainers time to investigate and coordinate a fix before
public disclosure. Do not test against infrastructure or data that you do not
own or have explicit permission to use.
